# Security Policy

## Reporting a vulnerability

If you find a security issue in this portfolio site, please report it privately by email to `263441505@ccmailg.meijo-u.ac.jp`.

Please include the affected URL or file, steps to reproduce the issue, and the impact you observed. Do not open a public GitHub issue for vulnerabilities that expose private data, credentials, or an exploitable weakness.

I will review reproducible reports and update the site when a fix is needed.

The canonical security contact is also published at `https://sakai1250.github.io/.well-known/security.txt`.
